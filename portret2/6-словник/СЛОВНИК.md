# Словник і переворот

Сировина методу. Слова в не-літературному значенні, якими ти описуєш своє життя.

| Твоє слово | На 180 |
|---|---|
| потеряшка | на своєму місці |
| рамка | плинність |
| тотально, без залишку | потроху, частинами |
| найобка | варте |
| какофонія | ясність |
| вкластися | приберегти себе |
| разом | сам |
| чужий | свій |
| поки тут, а далі | вже і назавжди |
| вийобуються | щирі |
| мільярд / гривня | накопичення |
| дім | дорога |
| побачити | пояснити |
| не робити хуйні | вкластися єством |
| безрамочність | відкритість |

## Що з цього вийшло
Два наскрізні мотиви, які й дали пари:

**свій / чужий** → [[АІ-1 Впізнаний — Невидимий]]
**мільярд / гривня** → [[АІ-2 Тотальність — Розпорошення]]

Третій, менш певний: **чесне / найобка** → [[АІ-3 Чесне — Найобка]]

## Найважливіше слово
**Потеряшка.** Твоє власне, з поясненням «не в поганому сенсі». Дві сторони однієї монети: людина без орієнтації — і людина, яка може зорієнтувати себе сама. Обидві — ти.

## Домашнє за методом
Взяти власний словник і почати говорити перевернутим. Не змінювати життя — змінити слова, якими ти його описуєш, і подивитись, що станеться.
